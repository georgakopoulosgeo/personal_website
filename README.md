# personal_website

Personal website of Giorgos Georgakopoulos, a static site (plain HTML and CSS, no build step).

- `index.html`: the page content
- `styles.css`: the styles
- `assets/`: images and favicon

To preview locally, open `index.html` in a browser or run `python3 -m http.server`.
Deploys as-is to Vercel or GitHub Pages.
